# Sushi Mir — сайт доставки суші

## Структура
- `index.html`, `styles.css`, `app.js` — статичний адаптивний сайт.
- `netlify/functions/order.js` — безпечніший серверний проксі до Telegram Bot API.
- `bot.py` — альтернативний Python HTTP-приймач замовлень (aiogram 3 + aiohttp).

## Важливі застереження перед запуском
1. **Пароль адмінки в `app.js` — лише демонстраційний.** Він доступний у вихідному коді браузера. Не використовуйте його для захисту реальної адмінки. Для реального магазину потрібна серверна авторизація (наприклад Supabase Auth) та серверне збереження каталогу.
2. Каталог і кошик зберігаються у `localStorage` конкретного браузера. Це переживає перезавантаження сторінки, але не синхронізується між пристроями/клієнтами й може бути очищене користувачем. Для спільного меню підключіть Supabase або Netlify Blobs.
3. Для Netlify рекомендовано використовувати **Netlify Function**: токен бота зберігається в Environment variables і не потрапляє у браузер. `bot.py` — альтернативний спосіб прийому POST, його треба розмістити на окремому Python-хостингу. Не вмикайте обидва варіанти одночасно для одного сайту.

## Деплой на Netlify (приблизно 5 хвилин)
1. Створіть GitHub-репозиторій та завантажте в нього файли цього проєкту.
2. На Netlify оберіть **Add new site → Import an existing project**, під'єднайте репозиторій.
3. Build command залиште порожньою, Publish directory вкажіть `.`. `netlify.toml` уже містить ці параметри та шлях до функцій.
4. У налаштуваннях сайту відкрийте **Environment variables** і додайте:
   - `BOT_TOKEN` — токен від @BotFather;
   - `ADMIN_CHAT_ID` — ID особистого чату або групи, куди надсилати замовлення;
   - за бажанням `ALLOWED_ORIGIN` — домен вашого сайту, наприклад `https://example.netlify.app`.
5. Запустіть **Deploys → Trigger deploy**. Перевірте замовлення на опублікованому сайті.

### Як отримати chat ID
- Напишіть своєму боту `/start`.
- Для приватного чату можна тимчасово використати `getUpdates` Telegram Bot API або невеликий скрипт, щоб подивитися `message.chat.id`.
- Для групи додайте бота до групи, надайте право надсилати повідомлення та отримайте ID групи (часто починається з `-100`).
- Не публікуйте токен бота в GitHub, HTML або JavaScript.

## Запуск Python-приймача (альтернатива Netlify Function)
Потрібен Python 3.10+:
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```
Встановіть змінні середовища (не комітьте секрети в репозиторій):
```bash
# macOS/Linux
export BOT_TOKEN="123456:your-token"
export ADMIN_CHAT_ID="123456789"
export PORT=8080

# Windows PowerShell
$env:BOT_TOKEN="123456:your-token"
$env:ADMIN_CHAT_ID="123456789"
$env:PORT="8080"
```
Запустіть:
```bash
python bot.py
```
Перевірка: відкрийте `http://localhost:8080/health` — очікується `{"status":"ok"}`.
POST endpoint: `https://ВАШ-PYTHON-HOST/order` з JSON у форматі, який надсилає `app.js`.

Якщо використовуєте Python-сервер, змініть `ORDER_ENDPOINT` у `app.js` на публічний HTTPS URL, а сервер налаштуйте на CORS лише для домену магазину, додайте rate limiting і захист від спаму. Для простого тесту можна запустити локально через ngrok, але не залишайте тестовий тунель як production.

## Дані та безпека
- Цей комплект — готовий стартовий шаблон, а не повноцінна комерційна платформа.
- Перед прийомом реальних оплат додайте платіжного провайдера; зараз оплата не інтегрована.
- Додайте серверну перевірку цін із каталогу (не довіряйте сумам, які надіслав браузер), rate limiting, CAPTCHA/антиспам, політику конфіденційності та резервне копіювання.
- Завантажені через адмінку файли не завантажуються на сервер: форма приймає URL картинки. Зміни каталогу зберігаються лише в localStorage цього браузера.
